# Hurricane Relief System
When a hurricane hits, chaos doesn't wait for anyone. Roads close, power goes out, and suddenly thousands of people need the same three things at once: **shelter, supplies, and answers**. Too often, help gets lost somewhere between a frantic phone call, a sticky note, and a spreadsheet nobody can find.

This Java-based project exists to bring order to the storm. The Hurricane Relief System connects people who need help with the resources that can provide it. It tracks active hurricanes, manages shelters and their availability, and organizes relief requests so nothing (and no one) falls through the cracks.

Think of it as **mission control for disaster relief**. Less panic, more coordination: the right help, in the right place, at the right time.
